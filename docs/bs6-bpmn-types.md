# Типы шлюзов, событий и триггеров BPMN в Business Studio 6

Снято с работающего Business Studio 6 (КМЗ, диаграмма A3.1 C025.02.01): правый щелчок по фигуре → «Тип шлюза», «Тип события», «Тип триггера».
Названия — дословно из меню. Меню только открывались, ничего не менялось.

## Шлюзы — «Тип шлюза» (7)

| № | Название в Business Studio | У нас (`subtype`) |
|---|---|---|
| 1 | Эксклюзивный шлюз | `exclusive` |
| 2 | Неэксклюзивный шлюз | `inclusive` |
| 3 | Параллельный шлюз | `parallel` |
| 4 | Комплексный шлюз | — **нет** |
| 5 | Эксклюзивный шлюз по событиям | `event_based` |
| 6 | Эксклюзивный шлюз по событиям (для запуска процесса) | — **нет** |
| 7 | Параллельный шлюз по событиям (для запуска процесса) | — **нет** |

## Типы событий — «Тип события» (4)

| № | Название в Business Studio | У нас |
|---|---|---|
| 1 | Стартовое событие | `start` |
| 2 | Промежуточное событие (Обработчик) | `intermediate`, ждёт (`catch`) |
| 3 | Промежуточное событие (Инициатор) | `intermediate`, выбрасывает (`throw`) |
| 4 | Конечное событие | `end` |

Граничных событий в этом меню нет (в Business Studio они ставятся на границу задачи отдельно).

Порядок пунктов:

- промежуточное (Обработчик): Сообщение, Таймер, Условие, Ссылка, Сигнал, Множественное, Параллельное множественное;

## Сравнение с нашим набором (`server/src/shared/events.ts`, `allowedTriggers`)

- Стартовое: совпадает полностью.
- Промежуточное (ждёт): совпадает полностью.
- Конечное: у нас дополнительно есть «Отмена» (`cancel`), в Business Studio её нет.
- Промежуточное (выбрасывает): у нас Неопределенное, Сообщение, Сигнал, Эскалация, Компенсация, Ссылка, Множественное — сверить с Business Studio нельзя без примера.
- Граничные события и триггер «Отмена» — у нас есть, в меню Business Studio для снятых событий их не было.
- Шлюзы: у нас нет «Комплексного» и двух шлюзов «для запуска процесса».

# Из папки установки: трафарет `BYTE_STENCIL.vss`

Файл `C:\Program Files (x86)\STU-Soft\Business Studio 6\BYTE_STENCIL.vss` — трафарет Visio с мастерами BPMN: `BPMN Event`, `BPMN Gateway`, `BPMN Action`
(задача), `BPMN Data Object`, `BPMN Database`, `BPMN Collapsed Pool` (всего в файле 49 мастеров, остальные — прежние: Process, Decision, Event, Operator…).
Открыт в Visio только на чтение; из него прочитаны имена, ячейки пользователя и условия показа частей фигур (`NoShow`). Файл и картинки не копировались.

Тип BPMN-фигуры задаётся в ячейках пользователя мастера (раздел `User`); части фигуры включаются формулами.

## Событие (`BPMN Event`): ячейки `User.EventType`, `User.TriggerType`

`TriggerType` — битовое значение, части значка триггера показываются по равенству:

| Значение | Триггер | Часть фигуры |
|---:|---|---|
| 0 | Неопределенное | — |
| 1 | Сообщение | `MessageTr` |
| 2 | Таймер | `TimerTr` |
| 4 | Эскалация | `Escalation` |
| 8 | Условие | `Condition` |
| 16 | Ссылка | `linkTr` |
| 32 | Ошибка | `Error` |
| 64 | Отмена | `Cancel` |
| 128 | Компенсация | `CompensationTr` |
| 256 | Сигнал | `SignalTr` |
| 512 | Множественное | `MultipleTr` |
| 1024 | Параллельное множественное | `ParallelMultiple` |
| 2048 | Завершение | `Terminate` |

`EventType`: внутреннее кольцо (`IntermediateCircle`) рисуется при значениях 2, 4, 32 и 64; толстая чёрная рамка (`BlackBorder` с белой серединой) — при значении 1.
Отсюда: 1 — конечное событие; 2 и 4 — промежуточные («Обработчик» и «Инициатор», как в меню); 32 и 64 — ещё два варианта с двойным кольцом
(по устройству — граничные, прерывающее и непрерывающее; в меню «Тип события» они не показаны). Значение для стартового события — без кольца и без рамки (в стенсиле
значение по умолчанию 0). Соответствие чисел названиям выведено по условиям показа, а не прочитано подписью.

## Шлюз (`BPMN Gateway`): `User.GateType`, `User.ShowMarker`

| Значение | Что рисуется | Название в меню |
|---:|---|---|
| 8 (по умолчанию) | круг-метка при `ShowMarker = 1` | Неэксклюзивный шлюз |
| 16 | «X» (`ExclusiveData`) | Эксклюзивный шлюз |
| 32 | «+» (`Parallel`) | Параллельный шлюз |
| 64 | `Complex` | Комплексный шлюз |
| 128 | двойное кольцо с пятиугольником (`ExclusiveEvent`, слои `Sheet.9` и `Sheet.10`) | Эксклюзивный шлюз по событиям |
| 256 | то же, без внутреннего слоя | Эксклюзивный шлюз по событиям (для запуска процесса) |
| 512 | «+» и кольцо (`Parallel` вместе с `ExclusiveEvent`) | Параллельный шлюз по событиям (для запуска процесса) |

Соответствие чисел названиям меню — по порядку пунктов и условиям показа частей.

## Задача (`BPMN Action`): `User.TaskType`, `User.LoopType`, `User.Compensation`, `User.CallActivity`, `User.SubProcessType`

- `LoopType`: 1 — стандартный цикл, 2 и 4 — многократный (последовательный и параллельный).
- `Compensation` — значок компенсации; `SubProcessType = 1` — знак «+» подпроцесса; `CallActivity = 1` — вызываемая деятельность (толстая рамка).
- `TaskType` — значок типа задачи: 5 — транзакция (двойная рамка), 7 — ad hoc (тильда); значения 24, 40, 56, 72, 88, 120, 136 включают значки в части `TasksMarker`
  (пользовательская, сервисная, ручная и другие виды из «Тип задачи»); 8 — обычная задача.
