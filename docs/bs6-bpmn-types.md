# Типы шлюзов, событий и триггеров BPMN в Business Studio 6

Снято с работающего Business Studio 6 (КМЗ, диаграмма A3.1 C025.02.01): правый щелчок по фигуре → «Тип шлюза», «Тип события», «Тип триггера».
Названия — дословно из меню. Меню только открывались, ничего не менялось.

## Шлюзы — «Тип шлюза» (7)

| № | Название в Business Studio | У нас (`subtype`) |
|---|---|---|
| 1 | Эксклюзивный шлюз | `exclusive` |
| 2 | Неэксклюзивный шлюз | `inclusive` |
| 3 | Параллельный шлюз | `parallel` |
| 4 | Комплексный шлюз | — **нет** |
| 5 | Эксклюзивный шлюз по событиям | `event_based` |
| 6 | Эксклюзивный шлюз по событиям (для запуска процесса) | — **нет** |
| 7 | Параллельный шлюз по событиям (для запуска процесса) | — **нет** |

## Типы событий — «Тип события» (4)

| № | Название в Business Studio | У нас |
|---|---|---|
| 1 | Стартовое событие | `start` |
| 2 | Промежуточное событие (Обработчик) | `intermediate`, ждёт (`catch`) |
| 3 | Промежуточное событие (Инициатор) | `intermediate`, выбрасывает (`throw`) |
| 4 | Конечное событие | `end` |

Граничных событий в этом меню нет (в Business Studio они ставятся на границу задачи отдельно).

## Триггеры — «Тип триггера»

Набор зависит от типа события.

| Триггер | Стартовое | Промежуточное (Обработчик) | Конечное |
|---|:-:|:-:|:-:|
| Неопределенное | ✓ | | ✓ |
| Сообщение | ✓ | ✓ | ✓ |
| Таймер | ✓ | ✓ | |
| Условие | ✓ | ✓ | |
| Ссылка | | ✓ | |
| Эскалация | | | ✓ |
| Ошибка | | | ✓ |
| Компенсация | | | ✓ |
| Сигнал | ✓ | ✓ | ✓ |
| Множественное | ✓ | ✓ | ✓ |
| Параллельное множественное | ✓ | ✓ | |
| Завершение | | | ✓ |

Порядок пунктов:
- стартовое: Неопределенное, Сообщение, Таймер, Условие, Сигнал, Множественное, Параллельное множественное;
- промежуточное (Обработчик): Сообщение, Таймер, Условие, Ссылка, Сигнал, Множественное, Параллельное множественное;
- конечное: Неопределенное, Сообщение, Эскалация, Ошибка, Компенсация, Сигнал, Множественное, Завершение.

Для «Промежуточное (Инициатор)» набор триггеров не снимался: на открытой диаграмме нет такого события, а менять тип существующего без необходимости не стали.

## Сравнение с нашим набором (`server/src/shared/events.ts`, `allowedTriggers`)

- Стартовое: совпадает полностью.
- Промежуточное (ждёт): совпадает полностью.
- Конечное: у нас дополнительно есть «Отмена» (`cancel`), в Business Studio её нет.
- Промежуточное (выбрасывает): у нас Неопределенное, Сообщение, Сигнал, Эскалация, Компенсация, Ссылка, Множественное — сверить с Business Studio нельзя без примера.
- Граничные события и триггер «Отмена» — у нас есть, в меню Business Studio для снятых событий их не было.
- Шлюзы: у нас нет «Комплексного» и двух шлюзов «для запуска процесса».
