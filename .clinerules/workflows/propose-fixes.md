# Исправить замечания проверок

Рабочий процесс для проверки связки Cline → приложение: берёт замечания проверок сессии и предлагает исправления.

1. Вызовите `get_conventions`, затем `list_sessions` и выберите сессию (если их несколько — спросите у аналитика какую).
2. Вызовите `get_model` и выпишите замечания проверок (`error`, затем `warning`).
3. Для каждой группы однотипных замечаний, которые можно исправить без догадок, подготовьте **отдельное небольшое
   предложение** `propose_patch` (agent: «нормоконтролёр»; в `rationale` — код правила и элемент).
   Не исправляйте то, что требует знания предметной области (кто исполнитель, какой срок) — вместо предложения сформулируйте
   вопрос аналитику.
4. Вызовите `list_proposals` со статусом `rejected` и не повторяйте отклонённое без новых оснований.
5. Сообщите аналитику, сколько предложений отправлено и где их принять: вкладка «Предложения агентов» в студии.
