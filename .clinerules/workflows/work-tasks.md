# Выполнить задания аналитика

Рабочий процесс главного агента: забрать ожидающие задания сессии и выполнить каждое подходящей ролью.

1. `get_conventions`, `list_sessions` — выберите сессию (если несколько, спросите аналитика).
2. `get_tasks` — ожидающие задания. Нет заданий — сообщите об этом и остановитесь.
3. Для каждого задания определите роль по тексту и адресату (`agent`): структура и шаги из интервью — **моделист**
   (workflow `model-from-interview`), проверка и замечания — **нормоконтролёр** (`review-model`), вопросы для интервью —
   **интервьюер** (`interviewer`), анализ и улучшения — **аналитик** (`analyst`), прочее — отвечайте сами как **методолог**
   (`methodologist`: там же правила распределения и границы ролей).
4. `take_task` с ролью, затем работа по соответствующему workflow: предложения с `task_id`.
5. `complete_task`: итог для аналитика — что предложено, что осталось неясным, вопросы.
6. Задание выполняйте только в границах его `scope` (функции), если он указан.
7. В конце: сколько заданий выполнено, сколько предложений ждёт решения; напомните — применяет аналитик, вкладка
   «Предложения агентов».
