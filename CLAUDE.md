# CLAUDE.md — память проекта

Краткая выжимка соглашений проекта, чтобы не повторять одни и те же уточнения в каждой сессии.

## Что это

Веб-приложение для построения моделей IDEF0 и BPMN по текстовому интервью (ТЗ в корне: см. `README.md`).
npm-workspaces: `server` (Express + TypeScript + SQLite, `better-sqlite3`), `web` (React + Vite), плюс
`desktop/ProcessStudio` — настольная оболочка (.NET 8 WinForms + WebView2), в которой вместо холста редактора работает
**настоящий Visio**.

## Железные правила

1. **Веб-версия и настольная живут вместе.** Одна модель, одна база. Правки не должны ломать ни одну из них.
2. **Внешний вид и поведение — «1 в 1» как в Business Studio 6 (BS6).** Если делается элемент интерфейса или
   диаграммы, он сверяется с BS6; несделанные различия перечисляются честно.
3. **Чужое не копируем.** Берём идеи и форматы (имена свойств Visio, поведение), но не код, текстовые ресурсы и файлы
   Business Studio и Microsoft (EULA). Трафареты Microsoft в репозиторий не кладём — тестовые `.vsdx` собираем сами.
   Значки рисует наш код по стандарту BPMN.
4. **Совместимость модели.** Новые поля — только необязательные, старые модели читаются без миграции.
5. **Жесты:** двойной щелчок — правка текста, **Ctrl + двойной щелчок** — создание функции IDEF0 и излома стрелки.
6. **Диаграммы рисует детерминированный код, а не LLM.** LLM извлекает факты с цитатами; нотации, раскладка,
   валидация — наш код.

## Команды

```bash
npm run dev:server         # API, http://127.0.0.1:8787
npm run dev:web            # клиент, http://localhost:5173 (проксирует /api)
npm run typecheck          # типы (сервер и клиент)
npm test                   # vitest: сервер + клиент
npm run test:e2e           # сквозные (Edge на Windows)
npm run build              # сборка сервера и клиента (нужна для настольной оболочки)
npm run backup -w server -- --repo   # копия базы + репозиторий одним bundle
npm run hash-password -w server -- <пароль>   # хэш для AUTH_USERS
npm run seed:demo -w server                   # демо-процесс в базу
```

## Структура, о которой важно помнить

- `server/src/shared/` — геометрия диаграмм и общие модули; в клиенте алиас `@shared`. Правка здесь меняет и сервер, и
  редакторы, и выгрузки.
- `server/src/pipeline/` — конвейер (фрагментация → извлечение → пробелы → валидация → BPMN/IDEF0), `vsdxImport.ts` —
  приём правок и импорт из Visio.
- `web/src/components/studio/` — студия; `web/src/desktop.ts` — связь студии с настольной оболочкой
  (`inDesktopShell`, `postToShell`, `onShellMessage`).
- `desktop/ProcessStudio/` — оболочка: `Program.cs` (меню, сообщения), `VisioPane.cs` (Visio), `ServerHost.cs` (запуск
  сервера, в т.ч. `--selftest`).
- Метки фигур для Visio: `pm_k`, `pm_id`, `pm_n`, `pm_c`, `pm_a`, `pm_trg`, `pm_manifest`, `pm_page`, `pm_scope`,
  `pm_parent`, `pm_sr/pm_fd/pm_fk`.
- `docs/` — `plan-bs6-visio.md` (план по BS6 и статусы), `bs6-bpmn-types.md` (типы снятые с BS6 и трафарета),
  `manual-checks.md` (**что нужно проверить глазами**), `bs6/compare/` (**скриншоты BS6 ↔ приложение** — эталон
  вида IDEF0/BPMN, C025 и B002; только локально, в `.gitignore`), `desktop-setup.md` (окружение настольного приложения),
  `agents/` (доступ агентов), `claude-code-history/` (выгрузка и разбор прошлых сессий),
  `development-workflow.md` (**стек и как ведётся разработка**: команды, тесты, правила, окружение).

## Как проверять работу

1. `npm run typecheck` и `npm test` — обязательно; для клиентских правок ещё `npm run test:e2e`.
2. **Золотые снимки раскладки** не должны меняться без намерения: изменились — смотреть diff, а не обновлять наугад
   (`npx vitest run <файл> -u`).
3. Правки в настольной части — проверить самопроверкой оболочки (`--selftest`, см. `docs/desktop-setup.md`).
4. **Если что-то не проверено вживую — так и написать.** В отчёте: что сделано, номер коммита, что проверено тестами, а
   что глазами нет. В прошлых сессиях это правило ловило реальные ошибки (значки событий «работали» в самопроверке и не
   работали на экране).
5. Пункты, требующие глаз, отмечать в `docs/manual-checks.md`.

## Окружение этой машины (важные грабли)

- **Сеть через прокси** (`HTTPS_PROXY` с учётными данными). `curl.exe` прокси уважает, `Invoke-WebRequest` в
  PowerShell 5.1 — нет; скачивание настроить через curl.
- **PowerShell 5.1 читает `.ps1` как ANSI** — кириллица в скрипте ломает разбор. Скрипты писать только ASCII, а пути с
  кириллицей («проекты») передавать параметром, не вписывать в файл.
- **.NET установлен для пользователя** (`%LOCALAPPDATA%\Microsoft\dotnet` + `DOTNET_ROOT`): рантайм 8.0.32 и **SDK 8.0.426**
  (поставлен 16.10.2026) — `dotnet build -c Release` для `desktop/ProcessStudio` работает. Рецепт установки и грабли
  (прокси, `Expand-Archive` не берёт архив SDK) — в `docs/desktop-setup.md`.
- Вход отключён (нет `AUTH_USERS`), сервер слушает только `127.0.0.1`. Включать вход без правки оболочки нельзя —
  подробности и список ручек в `docs/desktop-setup.md`.
